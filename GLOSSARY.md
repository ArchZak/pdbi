# pdbi query pipeline

## Language

**Structured query**

The search criteria a researcher can review and run, whether entered manually or drafted by the wizard.

**Query run**

One execution of a confirmed structured query against the selected databanks.

**Sequence result**

One distinct full amino-acid sequence found by a query run, together with the source identifiers that supplied that sequence.

**Saved result**

The reconciled dataset produced by a completed query run. Researchers can download it in either supported format. Later downloads in the same format return the same bytes.

**Resume**

Continue an interrupted query run using its saved progress and original query.
